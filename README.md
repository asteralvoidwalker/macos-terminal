# macOS Terminal

A web-based macOS Terminal interface built with **HTML, CSS, and JavaScript**.

This project recreates the look and feel of the macOS Terminal inside a browser, while gradually adding interactive terminal features and functionality.

## 🚀 Features

* 🖥️ macOS-inspired Terminal interface
* ⌨️ Interactive command input
* 📂 Terminal-style command output
* 🎨 macOS-inspired UI
* ⚡ Built with vanilla HTML, CSS, and JavaScript
* 🔧 Designed to evolve with new terminal features

## 📂 Project

The goal of this project is to recreate a terminal experience in the browser while improving my understanding of:

* DOM manipulation
* JavaScript event handling
* Command parsing
* Web interfaces
* Frontend architecture
* Interactive UI development
